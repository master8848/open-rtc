# Recording — client, SFU egress, storage

Current behavior for `packages/core/src/recording/*`, `packages/server/src/recording.ts`, `packages/server/src/egress.ts`, `packages/core/src/media/egress.ts`.

Surface: `room.recording` is `RoomRecordingFacade` (`packages/core/src/recording/room-recording-facade.ts:74`) wrapping `CompositeRecordingHook` + optional `RecordingUploader`. Events `recording:started|stopped|error|blob-chunk`, methods `startRecording`/`stopRecording`/`pause`/`resume`/`getStatus` (`packages/core/src/recording/room-recording-facade.ts:118`).

Modes behind one surface: `client` composites `localStream`+`remoteStreams[]` via `MediaRecorder` into `.webm` chunks (zero infra, tab-owned; `CompositeRecordingHook` + `MediaRecorderRecordingHook`); `sfu-selective` writes one file per SFU `Consumer` via `PlainTransport` (no mixing, per-track retention); `sfu-composite` mixes consumers via `ffmpeg`/`gstreamer` `PlainTransport` → `mp4`/`webm`/`m3u8` (server truth, HLS/RTMP). `RecordingMode` and `RecordingLayout` (`grid|spotlight|custom`) are in `packages/core/src/recording/recording-hook.ts`. `room.recording.startRecording({ mode, localStream, remoteStreams, layout, egress:{hls,rtmpUrl}, encryption, timesliceMs })` selects mode; default `client` on mesh, `sfu-composite` when `media.kind==='sfu'`.

Client flow: `CompositeRecordingHook` composes streams, emits `blob-chunk` with sequential `index`; `FetchRecordingUploader` (`packages/core/src/recording/recording-uploader.ts`) `POST /recordings/:id/chunks?index=n` (sequential gap rejected `packages/server/src/recording.ts:75`) + `POST .../finalize`. SFU flow: `SfuGateway.egress` → `FfmpegEgressWorker` (`packages/core/src/recording/sfu-egress.ts:19` `createEgressWorker` feature-flagged `enabled:true`, `packages/sfu-gateway/src/mediasoup-adapter.ts:193` `startEgress`/`stopEgress` `PlainTransport` lifecycle, `PlainTransport` RTP → `ffmpeg -i pipe:0` → `RecordingStorage`).

Storage: `RecordingStorage` interface `saveChunk/finalize/getStream/delete` (`packages/server/src/recording.ts:24`) with `FinalizeManifest` (`packages/server/src/recording.ts:35`) fields `sessionId`, `chunks`, `bytes`, `finalizedAt`, optional `encrypted`, `keyId`, `mimeType`, `mode`. `DiskRecordingStorage` (`packages/server/src/recording.ts:64`) layout `dir/<sessionId>/chunk-000000`+`manifest.json`; `S3RecordingStorage` (`packages/server/src/recording.ts:166`) via `fetch`+SigV4 `aws-sigv4.ts`, prefix `prefix/sessionId/chunk-...`+`manifest.json`.

Server API: `POST /rooms/:roomId/recordings/start` → `{sessionId}`, `POST /recordings/:sessionId/chunks?index=n` → `201` (sequential), `POST /recordings/:sessionId/finalize` → `{chunks,bytes,manifestUrl}` + `manifest.encrypted`/`keyId` surfaced, `GET /recordings/:sessionId/manifest`, `GET /recordings/:sessionId/stream` with `Range: bytes=` → `206` `Content-Range` or `200`, `DELETE /recordings/:sessionId` (`packages/server/src/http.ts`, `packages/server/src/recording.ts:105/281`).

Encryption: when `encryption:{key,keyId}` is set, `RoomRecordingFacade.uploadChunk` (`packages/core/src/recording/room-recording-facade.ts:208`) encrypts each `Blob` with AES-GCM 12-byte nonce prepended (`packages/core/src/recording/encryption.ts:29` `encryptBlob`/`decryptBlob`) and `manifest.encrypted=true`+`keyId`; key never persisted. With `policy.e2eeRequired` (`packages/server/src/core.ts:129`), egress that needs plaintext fails `code:'e2ee-blocks-egress'` (`packages/core/src/recording/room-recording-facade.ts:131`) or records ciphertext with `keyId`.

Consent: `caps.record` (`docs/security.md:17`) + `RoomPolicy.allowRecording` gate `POST /rooms/:roomId/recordings/start` (`packages/server/src/http.ts:548`); UI must show recording indicator and obtain participant consent before `startRecording`.

Lifecycle: `Store.RecordingSession` `expiresAt` is reaped by server cron `DELETE /recordings/:id`; `DiskRecordingStorage.delete` (`packages/server/src/recording.ts:128`) and S3 lifecycle rule are second layer; `GET /stream` supports `Range` (`packages/server/src/recording.ts:105/281`).

Transcription sidecar: when STT enabled, `RecordingSession.transcriptUrl` (`packages/server/src/types.ts:103`) points to transcript artifact; webhooks `transcript.final`/`transcript.interim` (`packages/server/src/webhooks.ts:12`, `packages/server/src/transcription-worker.ts`) emit alongside `recording.finalized`.
